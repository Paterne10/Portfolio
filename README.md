# Portfolio

Site portfolio présentant mes différents projets personnels et clients en tant que developpeur web Full stack et aspirant SOC.

## Pages

- `index.html` — Accueil : présentation rapide et projets à la une
- `about.html` — À propos : bio, compétences et expérience
- `projects.html` — Projets : tous les projets, classés en trois sections (Développement web, Projets clients, Cybersécurité)
- `contact.html` — Contact : coordonnées et formulaire

## Visiter le site

Le site est disponible via le lien `https://paterne10.github.io/Portfolio/`


## Technologies

HTML, CSS et JavaScript natifs. Polices via Google Fonts (Sora, Inter). Icônes via Tabler Icons (CDN).
